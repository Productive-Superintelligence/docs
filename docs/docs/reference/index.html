Psi surface map.

The PSI tools share package refs and service-shaped resources, but each project owns a narrow public boundary.

PsiCLI psi init, psi inspect, and psi launch for local users and scripts. PsiHub Python APIs for package metadata, validation, local hub storage, cards, config templates, and local hub apps. Low-Level Language Models (LLLM) Tactic protocol, service adapters, runtimes, remote clients, and PsiHub metadata helpers. Simple System of Systems Network (SSSN) Channel, event, artifact, snapshot, store, server, client, and resolver APIs. Advanced Autonomous Agent Executor (AAAX) Strategy, mounted resources, package serving, shell endpoints, and handoff surfaces.
