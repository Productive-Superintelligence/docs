Tutorial

Install, inspect, launch.

PsiCLI prepares local credentials and launches package resources. PsiHub validates, stores, downloads, and renders package metadata.

1. Install The Local Tools Install the command line, package hub, and framework packages together for local PSI work. 
python -m pip install prosi-psi-cli psihub lllm-core sssn aaax
2. Validate A Package Use PsiHub from Python when package metadata checks belong inside scripts or apps. 
from psihub import validate_package

report = validate_package("packages/analyst-tactics")
assert report.ok
3. Prepare Credentials Use PsiCLI before launching packages that declare provider keys. 
psi init packages/analyst-tactics
psi inspect packages/analyst-tactics --json
4. Launch Locally Launch the package's primary resource as a local FastAPI service. 
psi launch packages/analyst-tactics --port 8000
