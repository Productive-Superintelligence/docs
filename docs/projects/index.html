Flagship frameworks.

LLLM Tactic Framework, SSSN Semantic Channel Network, and AAAX Agentic Application Shell are the flagship PSI framework trio. Each keeps one center abstraction, one implementation layer, and one service surface so systems can stay small alone and compose uniformly as servers.

One framework, one abstraction, one layer. Shared structure makes Tactics, Channels, and Shells packageable, inspectable, and callable through the same PSI service grammar.

Tactic framework / Runtime layer Channel framework / Backend layer Strategy framework / Shell layer
LLLM Tactic Framework: Tactic + Runtime A Tactic is the reusable unit of agentic work. Runtime adapters make Python, Pydantic AI, native LLLM, and future runtimes share one callable service surface. SSSN Semantic Channel Network: Channel + Backend A Channel is the semantic data contract. Backend implementations provide local stores, HTTP services, remote clients, and future data systems behind the same abstraction. AAAX Agentic Application Shell: Strategy + Shell A Strategy names mounted package resources. Shell surfaces expose that strategy as a CLI for humans, FastAPI for apps, and agentic context for Codex or Claude Code.
